# Braid & Bloom — upgraded edition

A responsive, single-page website for Black teenage girls to explore braids, edges, school hairstyles, natural hair care, skincare and nail care.

## Open it on your Windows computer
1. Download `braid-and-bloom.zip` and extract it.
2. Open the `braid_and_bloom` folder.
3. Double-click `index.html` to open the site in Edge or another browser.

Most interactions work without installing anything. An internet connection is needed for the external hairstyle photos and links.

## Brand icon files
- `icon.png` — square Braid & Bloom brand artwork used in the website header and social preview metadata.
- `favicon.png` and `favicon.ico` — browser-tab icon files.

Keep these image files in the same folder as `index.html` when uploading to GitHub Pages.

## Features
- Responsive layout for phones, tablets and computers
- Dark and light themes
- Searchable tutorial library with category filters
- Step-by-step lessons, saved favourites and completion tracking
- Style finder quiz and a random “Surprise me” style picker
- Daily hair, skin and nail-care checklist that resets each day
- Progress stats and achievement badges
- Skincare and nail-care guidance with product *types* rather than paid endorsements
- Links to external video searches and trusted safety information
- Local browser storage for preferences, favourites, routine ticks and progress

## Publish with GitHub Pages
1. Open your GitHub repository (or create one).
2. Upload `index.html` to the repository's root folder. You can also upload this README.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes and open the website URL shown in the Pages settings screen.

## Important notes
- This is a front-end website; it does not have accounts, a cloud database or cross-device syncing. Data stays in the current browser on the current device. Clearing browser data can remove it.
- Hairstyle photos are external inspiration images and need an internet connection. They are not guaranteed to show the exact steps in each lesson; use the written steps and video links as guidance. Replace photos only with images you own or have permission to use.
- Video links open YouTube or other external pages. Review videos before recommending them to younger visitors.
- Skincare content is general information, not a diagnosis or personal medical advice. Teen skincare is usually best kept simple; avoid harsh or complicated routines and ask a trusted adult or healthcare professional about persistent irritation or concerns.
- If you later add accounts, uploads or cloud syncing, use a secure backend and never put secret API keys in frontend code.

# Braid & Bloom — upgraded edition

A responsive, beginner-friendly hair, skincare and nail-care learning website with a black, pink and silver look.

## Features
- Searchable tutorial library and category filters
- Step-by-step lessons, favourites, progress tracking and badges
- Three-question hairstyle finder quiz
- Daily hair, skin and nail-care checklist
- Dark/light theme switch
- FAQ section and accessible skip link/focus states
- Share button that uses the device share sheet where supported or copies/shows the site URL
- Improved page metadata for search and link previews
- `sitemap.xml` and `robots.txt` for search discovery
- Installable web-app manifest and service worker for caching the site shell on supported browsers
- Local browser storage for preferences, saved looks and progress (no accounts or cloud sync)

## Upload to GitHub Pages
1. Download and extract the ZIP file.
2. Open the extracted folder. Select all the files inside it, including `index.html`, `icon.png`, `favicon.png`, `manifest.json`, `sw.js`, `robots.txt`, and `sitemap.xml`.
3. In the GitHub repository, choose **Add file → Upload files**.
4. Upload the files to the repository's main/root folder (the same folder as `index.html`). Do not upload the containing folder itself.
5. Click **Commit changes** and wait for GitHub Pages to finish deploying.
6. Open `https://praiseosazee2013-ctrl.github.io/Braid-Bloom/` and test the navigation, tutorial search, favourites, quiz and theme toggle.

## Notes
- The service worker caches the same-origin site shell. Remote hairstyle images and external video links still need internet access.
- Favourites and progress stay in the current browser on the current device; there are no user accounts, cloud database or cross-device sync.
- Photos are inspiration rather than guaranteed demonstrations of each step. Use written instructions and trusted video tutorials.
- Skin and hair information is general education, not diagnosis or medical advice. Stop routines that cause pain or irritation and ask a trusted adult or qualified professional for help.

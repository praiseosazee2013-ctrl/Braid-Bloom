# Braid & Bloom — Upgrade 4.0

A responsive, beginner-friendly hair, skincare and nail-care learning website.

## Features
- Searchable tutorial library with category filters and step-by-step lessons.
- Saved hairstyles, lesson completion, progress badges and a style finder quiz.
- Weekly Crown Club challenge and three optional mini-goals, saved locally in the browser.
- Daily routine checklist, theme switch, FAQs and share-link button.
- Search metadata, sitemap, robots file, app manifest and service-worker shell caching.
- Responsive layout and keyboard focus styles.

## Publish on GitHub Pages
Upload the files in this folder into the repository's published root folder, alongside any Google verification HTML file you already use. Do not upload the folder itself as a nested directory. In GitHub, open Settings → Pages and confirm the deployment branch and root folder.

## Notes
- Photos and external video links need an internet connection.
- Favourites, progress, challenges and checklist ticks stay in the current browser/device; there are no accounts or cloud syncing.
- Service-worker offline support covers the app shell and same-origin files; external photos and videos still require internet.
- Use photos only when you have permission. Hair and skin guidance is general information, not a diagnosis.

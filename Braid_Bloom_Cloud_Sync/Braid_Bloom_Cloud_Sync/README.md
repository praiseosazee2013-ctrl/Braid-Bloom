# Braid & Bloom — Version 6.0

Responsive beauty-learning website with tutorial discovery, favourites, Style Planner, Bloom Dashboard, daily goals, routine builder, and local backup export/import.

## Publish
Upload the files in this folder to the root of your existing GitHub repository `Braid-Bloom`, replacing old website files as needed. Keep your Google Search Console verification HTML files. Commit changes, wait for GitHub Pages, then refresh with Ctrl+F5.

## Privacy
Progress, favourites, routines and plans stay in the current browser. Exported backup files may contain this progress; keep them private. There are no accounts or cloud syncing. Routine reminders do not send notifications.

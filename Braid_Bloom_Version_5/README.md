# Braid & Bloom — Version 5.0

Responsive hair and beauty learning website with searchable tutorials, favourites, a style finder, daily care checklist, Crown Club challenge, progress badges, FAQs, and a new interactive Style Planner.

## Publish
Upload the files in this folder to the root of your existing GitHub repository `Braid-Bloom`, replacing the old website files when prompted. Keep your Google Search Console verification HTML file. Commit changes and wait for GitHub Pages to deploy, then refresh the live site with Ctrl+F5.

## Notes
The site is static. Favourites, checklists, and style plans are stored in each visitor's browser on that device; there are no accounts or cloud syncing. External links and images may require internet access. Comfort comes first: loosen or remove a hairstyle that pulls or hurts.
